# Powered specificity run: ipTM tracks peptide composition, not binding

**Question.** At n = 11 receptors the Boltz-2 specificity test could not resolve
the effect either way (p = 0.094 two-sided, bootstrap CI containing chance). A
power analysis put 80% power at **21 receptors** (dz = 0.57). This is that run:
**22 receptors, 132 complexes**, PTM-clean panel, Boltz-2, 0 failures.

## The specificity test passes

| competitors | n | cognate #1 | mean rank | chance | 2-sided | bootstrap 95% CI |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| decoys only | 22 | 8 | **2.00** | 2.50 | **0.034** | **[1.59, 2.41]** |
| decoy + scrambled | 22 | 5 | 2.86 | 3.50 | 0.114 | [2.18, 3.59] |

Against decoys the CI **excludes chance**. Taken alone this is the positive
result the run was sized to detect, and it would overturn the n = 11 conclusion.

It should not be taken alone.

## The scramble control refutes the binding interpretation

| class | n | mean ipTM |
| :--- | :---: | :---: |
| cognate | 22 | 0.5015 |
| **scrambled** | 44 | **0.4888** |
| decoy | 66 | 0.4317 |

Two observations kill the binding reading:

**1. Cognates do not beat their own scrambles.** A scramble preserves amino-acid
composition and length exactly and destroys only order. Order is what makes a
binder a binder.

```
cognate higher than its own scrambles for 11/22 receptors
mean difference  +0.0128
t-test           p = 0.416      -> no difference
```

**2. Scrambles outscore decoys** — AUC 0.368 for decoy > scrambled, p = 0.019.
Sequence-order garbage beats genuine peptides that bind a different receptor.

The variable that separates cognate from decoy is therefore the one cognate
shares exactly with its scramble: **composition**. The variable that would
indicate binding — order — contributes nothing measurable.

## It is not merely a length artifact

Score falls with peptide length (Spearman −0.408, p = 1.2e-6), so length was
tested as the confound directly. Regressing the per-pair cognate-minus-decoy
score difference on the corresponding length difference gives slope −0.0112
(p = 0.0008) and **intercept +0.0752 (p = 0.0001)**. The cognate advantage
survives length adjustment.

So the effect is real and is *not* length. It is composition — which the
scramble control shows carries no binding information.

## Conclusion

**The powered run resolves the question, and the answer is still negative, now
with a mechanism.** ipTM responds to peptide amino-acid composition. It does not
respond to sequence order, and it ranks a scrambled sequence as highly as the
real binder it was made from. A screening reference must prefer the binder over
its own scramble; this one does not.

This converges with the independent surrogate result: a ridge regression on
additive amino-acid composition predicted ipTM better than the distilled neural
surrogate (+0.103 vs −0.034, z = 3.44). Two different routes reach the same
place — the signal available here is compositional.

**Consequence.** Reporting only the decoys-only row (p = 0.034) would have
produced a positive headline that the run's own control contradicts. The
cognate-versus-own-scramble comparison is the test that matters for a screening
reference, and it is flat.
