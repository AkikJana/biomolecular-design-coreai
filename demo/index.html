Boltz-Fast — what the measurements actually showed

Every figure on this page is read from the run artifacts, not typed in. Rebuild with python src/build_demo_site.py

1. The control that decides everything

A screening score must prefer a binder to a scramble of itself — identical composition and length, order destroyed. Without that control a benchmark cannot tell binder recognition from composition sensitivity.

2. The settings confound — and it was real

Same model, same device, same 132 pairs. Only the sampling settings change. Click to switch.

A full-settings fold takes 106 s on the laptop this was run on, and is no slower at full alignment depth. The obstacle was the device, not the settings — the reduced regime outlived the constraint that justified it.

3. Why: at ten steps the coordinates are not a protein

A peptide bond fixes consecutive alpha-carbons at 3.80 Å. Measured over every consecutive CA–CA distance.

4. One draw is not a measurement

Cognate rank among its own decoys, across five independent draws of the identical held-out panel. Chance is 2.50. The highlighted cell is draw 3, which reversed a conclusion drawn from the first two.

Draw 1 alone said interface pLDDT collapses held out. Draws 1–2 said ipTM specifically survives and interface pLDDT specifically fails. Draw 3 reversed the ordering — both claims were withdrawn.
